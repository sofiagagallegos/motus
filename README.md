# MOTUS · Sitio web

Sitio estático de MOTUS, consultora estratégica: «Todo en una misma dirección».

- `index.html`: la página completa (HTML + CSS + JS sin dependencias).
- `assets/motus-logo.png`: el logo.

## Publicar en GitHub Pages

En el repositorio, entra a **Settings › Pages**. En **Source**, elige **Deploy from a branch**, luego la rama y la carpeta `/ (root)`, y guarda.
